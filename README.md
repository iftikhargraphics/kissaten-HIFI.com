# Kissaten HiFi Website

Premium single-page HTML/CSS/JavaScript website for Kissaten HiFi, San Francisco.

## Before publishing
- Replace `https://example.com/` in `index.html` and `sitemap.xml` with the real domain.
- Replace the remote image URLs with properly licensed/authorized image assets for production use. The included visual references were selected from public web sources for the requested design direction.
- Verify current menu, prices, opening hours, service options, and review count with the business before publishing.
- Confirm Google Maps/Instagram links and any third-party image usage rights.

## Files
- `index.html` — complete responsive website
- `robots.txt` — crawler configuration template
- `sitemap.xml` — sitemap template
